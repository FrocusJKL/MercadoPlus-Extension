# Mercado Plus

Extensión de Chrome que agrega mejoras visuales opcionales a Mercado Libre.

## Desarrollo

```bash
npm install
npm run dev
```

Para generar la extensión:

```bash
npm run build
```

Después abre `chrome://extensions`, activa el **Modo desarrollador** y selecciona **Cargar descomprimida** apuntando a `dist/`.

Consulta [spec.md](spec.md), [memory.md](memory.md) y [agent.md](agent.md) para conocer la arquitectura y las reglas del proyecto.
